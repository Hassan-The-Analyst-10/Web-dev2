# Personal Budget & Expense Tracker

## Project Overview

The Personal Budget & Expense Tracker is a simple web page designed to help users record and view their daily expenses. This Week 2 version builds on the HTML and CSS foundation created in Week 1.

## What I Built

The project contains an expense table with sample expense records showing the expense name, amount, category, and date. I also upgraded the expense form by adding a category dropdown with five options: Food, Transport, Rent, Entertainment, and Other. The page includes a budget-related image and an embedded YouTube video. I added a collapsible "How to use this tracker" section using the details and summary elements. CSS was used to style the table, form, buttons, inputs, and different sections of the page. I also used advanced CSS selectors including descendant selectors, direct-child selectors, nth-child, not, focus, and hover selectors. The Add Expense button is currently not functional because JavaScript will be added in a later week.

## How to Run

1. Download or clone the project from GitHub.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. The Budget Tracker page will be displayed.

## Files

* `index.html` - Contains the structure and content of the Budget Tracker.
* `style.css` - Contains the styling and advanced CSS selectors.
* `README.md` - Explains the project and how to use it.
